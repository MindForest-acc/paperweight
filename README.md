# 镇纸 Paperweight

一张常驻 macOS 桌面的宣纸卡片，随机显示《周易》《道德经》《孙子兵法》《墨子》《商君书》《庄子》《王阳明心学》《曾国藩家书》《毛泽东选集》里的句子，每条都配原文出处与白话释义。

九本书各有自己的纸色、书名字体和闲章——不看书名也知道是谁在说话。

![九本书的卡片预览](previews/sheet.png)

<sub>九本各取一张，明暗主题混排。上排：周易 · 道德经 · 孙子兵法；中排：墨子 · 商君书 · 庄子；下排：王阳明心学 · 曾国藩家书 · 毛泽东选集</sub>

## 安装

```bash
./build.sh && open 镇纸.app
```

需要 macOS 14+ 与 Xcode 命令行工具。构建产物 1.7 MB，纯 Swift，无第三方依赖。

首次打开若被 Gatekeeper 拦（ad-hoc 签名），在「系统设置 → 隐私与安全性」里放行一次即可。

## 用法

卡片常驻桌面，菜单栏有一个 `❝` 图标。

| 操作 | 行为 |
|---|---|
| 单击卡片 | 换下一句 |
| 拖动卡片 | 移动位置（自动记忆） |
| ⌥ 单击 | 收起 / 展开释义（默认展开）|
| ⌃⌥Space | 全局换一句（不需要辅助功能授权） |
| 点菜单栏图标 | 完整菜单 |

菜单里可调：**书目**（九本可任意组合）、**轮换间隔**（15 分钟 ~ 2 小时 / 不自动换，默认 45 分钟）、**排版**（横排 / 竖排 / 自动）、**正文字体**（宋 / 楷 / 仿宋 / 黑，五本书统一）、**外观**（跟随系统 / 浅色 / 深色）、**卡片宽度**、**窗口层级**（悬浮最上层 / 贴在桌面上）、收藏与只看收藏、开机自启。

**排版默认横排**。竖排好看，但要一个字一个字往下数，不是日常阅读习惯；想试的话在菜单 → 排版 → 竖排（短句会按断句分栏、去标点，是古籍本来的样子）。

## 语料

502 条，`Resources/corpus.json`。庄子 71 / 孙子兵法 69 / 道德经 65 / 毛泽东选集 57 / 王阳明心学 56 / 墨子 54 / 周易 52 / 商君书 41 / 曾国藩家书 37。

**收录标准**（宁少毋滥）：脱离上下文独立成立 · 能映射到今天的处境 · 语言有锋刃 · 不与已有条目语义重复。曾经收到过 400 条，按这套标准回头裁掉了 92 条——上下文依赖的残句（庄子「之二虫又何知」）、操作细则（孙子「车杂而乘之，卒善而养之」）、语义重复的近义条。裁掉的都留在 `archive-trimmed.json` 里，可随时取回。

只收能定位到原书的句子。

语料由模型知识写出，再逐条与维基文库公有领域底本做去标点全文比对，篇目归属以底本为准。**443/502 条通过原文 + 篇目校验**；其余 59 条（57 条毛选 + 2 条王阳明《年谱》）没有可检索的公有领域底本，在 JSON 里 `verified` 为 `null`，文本与出处**未经原书核对**。

校验抓到的问题、裁决过程和见证本清单见 [docs/product-design-2026-09-14.md](docs/product-design-2026-09-14.md) 第七节。

重跑校验：

```bash
python3 -m venv venv && ./venv/bin/pip install zhconv
./venv/bin/python scripts/fetch_sources.py && ./venv/bin/python scripts/verify2.py Resources/corpus.json
```

## 结构

**商君书**是九本里的异类，处理方式也不同。它有相当篇幅是明确主张削弱、愚化、驱使民众的操作手册——「民弱国强，民强国弱，故有道之国，务在弱民」（弱民篇）、「胜民之本在制民，若冶于金，陶于土也」（画策篇）、「以良民治，必乱至削」（说民篇）。**这些条目照收，不挑着只留「变法图强」那一面**：为了让它看起来温和而选择性收录，等于对读者撒谎，而这套语料的信用全建立在不美化上。处理办法是释义写实——直译它在说什么、它的逻辑为什么自洽、代价是什么，既不写成励志格言，也不写成道德训诫。视觉上它是九本里唯一用黑体做书名的，这同样是刻意的。

**道德经**用王弼通行本做底。马王堆帛书本也抓了，但没拿它当裁判——帛书是另一个传本而非同本见证，章序和用字差异太大（「大器晚成」帛书作「大器免成」），拿它否决通行文本只会把读者认得的句子全删光。65 条一次全过校验。顺带修掉一处误引：「天网恢恢」原文是**疏而不失**，不是流传更广的「疏而不漏」。

**周易**收的主要是**大象辞**——六十四卦每卦一句「君子以⋯」，天生就是独立成立的格言，不像卦爻辞那样离了卦象读不懂。政务礼制类（明罚敕法、议狱缓死、至日闭关）全部排除，只留能落到今天的 30 条，另加系辞、文言、爻辞 22 条。52 条全部通过底本校验。

曾国藩这一本是**反过来做的**：先抓《曾国藩家书》原文，再从原文里挑，而不是凭记忆写。原因是探测发现我记忆里的「曾国藩名言」有 35/46 在底本中找不到——「莫问收获，但问耕耘」「扎硬寨，打呆仗」这类流传极广的句子，很可能是后人托名或概括。他是被鸡汤工业污染最重的一位。（注意：底本只是维基文库的家书选本约 4.5 万字，日记、书札均无，所以「找不到」只能说明未获见证，不等于证伪。）
